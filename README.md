# STREET RUSH

Mobile-first 3-lane endless runner. Plain HTML5 canvas + JavaScript — no build step, no backend.

**Play:** https://daneweslycuellar-cpu.github.io/street-rush/

## Controls
- Swipe left/right: change lanes
- Swipe up: jump (barriers)
- Swipe down: slide (yellow bars); in the air it slams you down
- Keyboard: Arrows / WASD, Space = jump, P = pause

Progress (best score, coins, upgrades, runners) saves in the browser's localStorage on each device.

## Updating
Edit `index.html`, bump `VERSION` near the top of the script, commit and push to `main`.
GitHub Pages republishes in about a minute. The version number shows at the bottom of the main menu.
